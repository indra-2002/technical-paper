
# Questions and Answers

## 1. Which command is used to remove a file recursively?

**Answer:** `rm -rf` — Removes files or directories recursively and forcefully.

## 2. What is the full form of ACID in SQL?

**Answer:** Atomicity, Consistency, Isolation, Durability — These are the four properties of reliable database transactions.

## 3. What is a constructor?

**Answer:** Constructor — A special method used to initialize an object when it is created.

## 4. What is the difference between `/` and `//` in Python?

**Answer:** `/` and `//` — `/` performs normal division, while `//` performs floor division.

## 5. How can you change directory permissions recursively?

**Answer:** `chmod -R` — Changes directory permissions recursively for all files and subdirectories.

## 6. What is Git cherry-pick?

**Answer:** Git cherry-pick — Copies a specific commit from one branch to another.

## 7. What are the four pillars of OOPs in Python?

**Answer:** Encapsulation, Inheritance, Polymorphism, Abstraction — These are the four pillars of OOP.

## 9. What is the difference between `break`, `continue`, and `pass`?

**Answer:** `break` exits the loop, `continue` skips the current iteration, and `pass` The pass keyword in Python is used when you need a statement syntactically, but you don't want the code to do anything.

## 10. How can you change the permissions of a directory?

**Answer:** `chmod` — Changes the permissions of a directory.

## 11. What is the SQL query to change the data type of a column in a table?

**Answer:** `ALTER TABLE table_name ALTER COLUMN column_name TYPE new_data_type;` 

## 12. What is the difference between NUMERIC and INTEGER?

**Answer:** NUMERIC and INTEGER — NUMERIC stores exact decimal numbers, while INTEGER stores whole numbers.
