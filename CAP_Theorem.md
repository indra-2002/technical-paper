# CAP Theorem

The CAP Theorem describes an important trade-off in distributed database systems. CAP stands for Consistency, Availability, and Partition Tolerance.

## 1. Consistency
Consistency means that clients receive data according to the system's consistency guarantee after an operation.

## 2. Availability
Availability means that the system continues responding to requests even when some components fail.

## 3. Partition Tolerance
Partition tolerance means the system continues operating despite communication failures between nodes.
