# AMA Questions and Answers

## Why are media queries used in CSS?
- Media queries are used to make a website responsive for different screen sizes like mobile, tablet, and desktop.

## What is the Dependency Inversion Principle (DIP) in SOLID?
- DIP says that high-level classes should not depend directly on low-level classes. Both should depend on abstractions.

## What are the different types of constraints in SQL?
- The main constraints are PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, CHECK, and DEFAULT.

## What is the order of execution of an SQL query?
- The basic order is FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT.

## What is the required attribute in HTML?
- The required attribute makes a form field mandatory. The user must enter a value before submitting the form.

## Which HTML tag is used to create a line break?
- The `<br>` tag is used to create a line break.

## What are HTML forms, and why are they used?
- HTML forms are used to collect information from users, such as names, emails, and passwords.

## Why is the LIMIT clause used in SQL?
- The LIMIT clause is used to restrict the number of rows returned by a query.

## What is a foreign key in SQL?
- A foreign key is a column that links one table to another table using the primary key of the other table.

## What is the difference between id and class in HTML?
- An id uniquely identifies one element, while a class can be used for multiple elements.

## What is the difference between CHAR and VARCHAR in SQL?
- CHAR stores fixed-length text, while VARCHAR stores variable-length text.

## What are semantic tags in HTML?
- Semantic tags clearly describe the meaning and purpose of the content. Common semantic tags include header, nav, main, section, article, and footer.
