## JSON.parse()

`JSON.parse()` is used to convert a JSON string into a JavaScript object.

## Callback Hell

Callback hell happens when many callbacks are nested inside each other, making the code difficult to read and maintain.

## Type Version

Type version refers to the version or type of something being used, depending on the context.

## Changing CSS Using JavaScript

We can change the CSS of an HTML element using JavaScript with the `style` property.

## Promise.all()

`Promise.all()` is used to run multiple promises together and wait until all of them are completed. If any promise fails, the whole `Promise.all()` fails.

## Promise.race()

`Promise.race()` is used with multiple promises and returns the result of the promise that finishes first.

## Spread Operator vs Destructuring

The spread operator is used to expand or copy values, while destructuring is used to extract values from arrays or objects.

## Web App

A web app is an application that runs in a web browser and allows users to perform different tasks through a web interface.

## DOM

DOM stands for Document Object Model. It represents an HTML document as a tree of objects and allows JavaScript to access and modify HTML elements.

## `.then()`, `.catch()`, and `.finally()`

`.then()` is used when a promise is successfully completed.

`.catch()` is used when a promise fails.

`.finally()` runs after the promise is completed, whether it succeeds or fails.

## `sudo` Command

`sudo` is a command used in Linux to run another command with administrator or superuser privileges.

## Normal Function vs Arrow Function

A normal function has its own `this` depending on how it is called, while an arrow function does not have its own `this` and uses `this` from its surrounding scope.

## `this` Keyword with an Object

Inside an object's method, `this` refers to the object that is calling the method.
