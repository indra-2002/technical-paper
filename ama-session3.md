## What is O in SOLID?

O stands for Open/Closed Principle. A class should be open for extension but closed for modification.

## How many ways can we add values in Python?

Values can be added using `+`, `append()`, `extend()`, `insert()`, and `update()` depending on the data type.

## What is data?

Data is a collection of facts, values, or information.

## Which Git command is used to initialize a repository?

`git init`

## Which command is used to create a commit?

`git commit -m 'message'`

## How to check the remote repository in Git?

`git remote -v`

## What is the difference between `<strong>` and `<b>` tags?

`<strong>` gives importance to the text, while `<b>` only makes the text bold.

## What are local and global variables in Python?

A local variable is declared inside a function and is available only there. A global variable is declared outside functions and can be accessed throughout the program.

## What is the difference between `find` and `grep`?

`find` is used to search for files and directories. `grep` is used to search for text inside files.

## What is the difference between a list, tuple, and dictionary in Python?

A list is ordered and changeable. A tuple is ordered and unchangeable. A dictionary stores data as key-value pairs.

## What is `self` in Python?

`self` refers to the current object of a class.

## What are the different types of selectors in CSS?

Element selector, class selector, ID selector, universal selector, attribute selector, and pseudo-class selector.

## Give an example of a wildcard character in CLI.

`*` is a wildcard character used to match multiple characters.
